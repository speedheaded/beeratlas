# Пивной атлас Праги — beeratlas.eu

**Начните отсюда.** Этот файл — полная передача состояния для новой сессии.
Прочитав его, можно продолжать работу, не поднимая переписку.

Проект: англоязычный справочник чешского пива, где каждый сорт описан через
расстояние до пива, которое читатель уже пробовал, и где каждая страница
заканчивается ответом «где это выпить, почём и когда мы это проверяли».

Начат 29 августа 2026. **Сайт живёт на своём домене: https://beeratlas.eu**
Код и данные в приватном репозитории `speedheaded/beeratlas`, ветка `main`.
Выкладка — Vercel, деплой на каждый push в `main`.

## Быстрый старт

```bash
cd E:/python/Beergraph
python scripts/ingest.py            # Wikidata + OSM -> data/  (сеть, ~2 мин)
python scripts/enrich_breweries.py  # тексты пивоварен, курируемые правки
python scripts/build_beers.py       # полные сорта: векторы, технология
python scripts/fetch_lineups.py     # линейки с сайтов пивоварен (сеть, ~30 мин)
python scripts/fetch_shelf.py       # бутылки и этикетки из Open Food Facts (сеть)
python scripts/build_listed.py      # второй уровень каталога из снятого сырья
python scripts/check_cs.py          # языковой паритет (сборка гоняет половину сама)
python scripts/build_mockup.py      # -> index.html (корень: его отдаёт Vercel)
```

В сеть ходят три шага: `ingest` (Overpass иногда упирается в лимит, скрипт
сам повторяет три раза), `fetch_lineups` (headless-браузер по сайтам, около
получаса) и `fetch_shelf` (Open Food Facts отвечает 503 при частых запросах,
скрипт ждёт и повторяет). Остальное работает офлайн за секунду.

Ежедневно нужны только последние три строки: снятое сырьё лежит в `data/`
и заново снимается, только когда пора обновить.

**Проверять вёрстку скриншотом до показа.** Headless Chrome есть на машине.
Осторожно: у него минимальная ширина окна около 500 px, поэтому
`--window-size=390` даёт не узкую вёрстку, а обрезанный снимок широкой. Узкий
экран проверять через страницу-обёртку с `<iframe width="390">`.

```bash
"/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new \
  --disable-gpu --hide-scrollbars --window-size=1400,2400 \
  --screenshot=out.png --virtual-time-budget=6000 \
  "file:///E:/python/Beergraph/index.html#/beer/svijansky-maz"
```

## Что уже работает в прототипе

- **Главная** — что делает атлас, живой пример подбора на настоящих данных,
  четыре честных числа, раздел про пометки достоверности, «чем это не является»
- **Подбор по якорю** — знакомое пиво плюс пять ползунков-отклонений, результаты
  ведут на страницы сортов
- **Страница сорта** — сравнение с якорем, описание, технология (шкала времени,
  что кладут, пять этапов с посудой варочного цеха), где выпить с телефонами, чярки
- **Страницы пивоварен** — тексты, линейка, пражские точки, ссылки на сайты
- **Разбор процесса**, типы налива с бокалами, страница обращения к
  пивоварням за исправлениями
- **Список заведений** сгруппирован по городским частям: Praha 1 … Praha 22
  с числом заведений, именные части после нумерованных, все 228 без обрезки
- **Распознавание бутылки** (`#/scan`) — три входа в один конвейер: штрихкод
  читает сам браузер локально, набор с этикетки ищет по каталогу без вызовов
  наружу, лестница из четырёх ступеней показывает, какая ответила. Штрихкод
  даёт ответ, название — кандидатов, и это видно на экране
- **Второй уровень каталога** — 55 строк: имя, степень, крепость, где выпить,
  адрес источника и дата, без описания вкуса. Отдельная страница у каждой,
  блок «Ještě vaří» на странице пивоварни, раздел в списке сортов
- **Знак сорта** — бокал в настоящем цвете пива, выведенном из EBC стиля.
  В списке 46 px без гравировки, на странице сорта 176 px с градусом,
  вытравленным на стекле. Второй уровень каталога бокала не получает:
  у тех 55 строк нет стиля, значит нет и цвета
- **Котва выбирается по вектору**, а не жёстко. Светлый лагер по-прежнему
  сравнивается с Урквеллом — он им и ближайший. Меняется у четырёх сортов:
  обе Matušky к Punk IPA, Hoegaarden и Weihenstephaner друг к другу
- **Шесть ползунков в подборе** — пять вкусовых и крепость. Шаг крепости
  0,25 п. п.; пока не тронут, в счёт не входит вовсе
- **Лист для домашней варки** на двух языках: рецепт чешского пилзнера на
  20 литров, живые цены beerex.cz, разбор процесса, ссылки в обе стороны
- **Фирменный знак** «золотой тацек» — пивная подставка в цвет пива.
  Две формы: символ без имени для шапки и фавиконки, полный с именем
  для аватара и печати
- **Полностью на двух языках** — интерфейс, все 40 описаний сортов, 24 текста
  пивоварен, вся технология с чешской терминологией. Проверено автоматическим
  обходом чешских маршрутов, а не на глаз

## Решения, которые не нужно переоткрывать

1. **Ядро** — «отклонение от знакомого якоря». Не «12°, 4,4%», а «как Pilsner
   Urquell, только менее горькое». Одна операция обслуживает четыре экрана.
2. **Направление** — энциклопедия. Инструмент гида и карта отложены как режимы
   поверх тех же данных.
3. **Ось схемы** — сорт привязан к заведению через пивоварню, а не напрямую.
   Связь с брендом живёт годами, статус кеги — три дня.
4. **Провенанс** — каждое значение несёт источник, метод и дату. `unverified`
   заблокирован для публикации сборкой, а не дисциплиной.
5. **Правило публикации** — нет заведения, нет плотности и крепости из источника
   → страницы сорта нет. Действует и для второго уровня.
6. **Глубина берётся из вычислений, а не из выдуманных фактов.** Технология
   делится на «известно про пивоварню» и «типовое для стиля», и это видно в UI.
7. **Дизайн-система** — «эмалевая вывеска и пивной картон». Утверждена
   пользователем; нейтральная редакционная подача была отвергнута как безликая.
8. **Домен** — `beeratlas.eu`. BeerGraph.eu остаётся редиректом.
9. **Языки** — английский и чешский, полный паритет. Чех читает česky, все
   остальные anglicky. Переключатель EN/CS в шапке, язык в адресе (`#/cs/…`),
   выбор запоминается. Русский — позже, тем же механизмом.
10. **Монетизация отложена** до февраля. Продажа бутылок исключена навсегда:
    акциз при дистанционной продаже платится в стране назначения.
11. **Два уровня каталога.** Полная страница стоит дорого — текст на двух языках,
    девять осей, разбор технологии, — поэтому их сорок. Строка каталога даёт
    меньше и не притворяется. **Уровень — про то, сколько мы можем сказать, а не
    насколько уверены:** числа второго уровня несут `official` и ссылку, а сорок
    полных страниц до сих пор стоят на `unverified`, набранном по знанию.
12. **Пивоварня — это завод, а не владелец.** Kozel варят в Велких Поповицах,
    и вода с рмутом там свои, хотя владеет Plzeňský Prazdroj. Владельцы меняются,
    заводы нет. Независимость показывать отдельным полем, а не подменой сущности.
13. **Фирменный знак — «золотой тацек».** Пивная подставка, напечатанная
    в цвет пива. Две формы, и это не дубль: **символ без имени** идёт в
    шапку и фавиконку, где имя уже стоит рядом словом; **полный с именем**
    — в аватар, картинку ссылки и печать, где знак остаётся один. Кольцо
    у символа толще, иначе исчезает на 24 px.
14. **Превью ссылки без картинки.** Только заголовок, описание и адрес.
    `og:image`, `twitter:card` и `apple-touch-icon` убраны сознательно —
    последний заодно не работал: iOS для него SVG не принимает.
15. **Котва на странице сорта — по вектору, но консервативно.** Светлый
    лагер всегда сравнивается с Урквеллом. Прочим ищется ближайшая, причём
    оси стиля весят больше. Если и ближайшая дальше 4 — остаётся Урквелл:
    сравнивать чешский тёмный лагер с ирландским стаутом на расстоянии 8
    значит снова сообщать «отличается во всём».
16. **Пятнадцать светлых лагеров численно ближе к Stella Artois**, чем к
    Урквеллу. Это сравнение сознательно не включено: верно по числам и
    негодно по существу.
17. **Тег OSM `brewery=*` — подсказка, а не сущность.** Пивоварня заводится
    только при подтверждении: запись в Wikidata либо строка в `CURATED_BRANDS`
    с названным основанием. Неподтверждённое остаётся на заведении как
    `brandHints`. Раньше каждое значение тега становилось пивоварней и получало
    сочинённый текст — сайт утверждал существование объектов, которых нет.

## Открытые вопросы

| Вопрос | Почему важно |
|---|---|
| **Чярка = «выпил» или «понравилось»?** | В чешском пабе палочка означает выпитое, а не одобрение. Смысл сдвинут в сторону лайка. Чех может прочитать буквально — тогда счётчик меряет не то. Спросить у пары чехов, например на сентябрьском обзвоне |
| **Векторы не различают светлые лагеры** | Klášter, Hubertus и Rychtář сидят почти в одной точке. Это правда, но подбор слабее всего именно в самой большой категории. Лечится чярками (от ~1000 голосов) или более тонкими осями внутри стиля |
| **13 марок ждут подтверждения** | arpus, falkon, chroust, kout, bad-flash, postriziny, slavkov — похоже, настоящие пивоварни, но подтверждения нет ни в Wikidata, ни линейкой. Показаны разделом «Značky, které jsme nepotvrdili» на странице пивоварен: марка и заведение, которое её называет |
| **Крупная пятёрка не берётся с их сайтов** | У Staropramen на странице сорта только «°C» и пустой процент, у Pilsner Urquell ни одного числа. Крепость закрыта через Open Food Facts, степень — нет. Она напечатана на этикетке, фотография есть, лицензия позволяет: читать при вычитке |
| **~~Якорь не адаптируется~~ — закрыт наполовину** | Выбор по вектору сделан 31 августа: Raptor теперь сравнивается с Punk IPA. Вторая половина ждёт **двух новых котв**, которых в данных нет: тёмного лагера (Köstritzer или Negra Modelo — Guinness слишком жжёный, расстояние 8.4) и янтарного (для Granát котвы нет вовсе). Девять осей на сорт, набранные руками |
| **Хэш-маршруты в индекс не попадут** | `#/beer/kozel-cerny` для поисковика не существует: всё после `#` на сервер не уходит. Стоп-сигнал брифа «150+ страниц в индексе к 15 декабря» **недостижим до перехода на настоящие адреса**. Переезд на Next.js из октябрьского плана — не косметика, а предусловие всей затеи с трафиком |

## Ближайшее

Технически всё, что можно построить **до первого читателя**, построено.
Осталось два шага, и оба не про код.

### 1. Сообщение знакомому про промокод

У пользователя есть знакомый, владеющий чешским дистрибьютором солода и
хмеля под Прагой. На вопрос «продаёшь домашним пивоварам или только
пивоварням» ответил: **обоим**. Отправляет по ЕС.

Просить надо мало: не долю и не партнёрство, а промокод, чтобы считать
приведённые заказы. Доля обсуждается потом, с цифрами на руках — это
разговор с позиции силы, а не просьба в воздухе.

**Ссылки в листе для варки ведут на beerex.cz** — это Rudná у Праги, у них
цены в евро публично, хмель по 100 г, солод по кило, отправка по миру.
Коммерческой договорённости нет, и на странице это сказано прямо.
Если знакомый — другой дистрибьютор, ссылки меняются в одном месте.

### 2. Пост в r/Homebrewing

Ссылка `beeratlas.eu/brew/czech-pilsner` готова: своё превью, свой знак,
две языковые версии, путь назад в атлас.

Порог успеха — **не деньги, а доказательство цепочки**: пять заказов по
промокоду означают, что она работает от рецепта до кассы. Пять заказов по
30 € с долей 10 % — это 15 €. Смешно, но это первые деньги снаружи.

**Перед постом сбросить кеши превью.** Telegram — боту `@WebpageBot`,
Facebook — их отладчиком. Иначе всплывёт старая карточка.

### Чего проект по-прежнему не знает

**Захочет ли англоязычный домашний пивовар варить чешский пилзнер из
чешских ингредиентов.** Это единственная непроверенная гипотеза, и за
31 августа она не сдвинулась ни на шаг: построено много, показано никому.

Обзвон 50–60 заведений из прежнего плана **снят с критического пути**:
он собирал групповую проходимость для гидов, а гиды вынесены за периметр.
Если продукт вернётся к пабам — вернуть и обзвон.
